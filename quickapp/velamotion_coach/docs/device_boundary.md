# 设备支持与边界（1.1.0）

- 原生硬件路径已补充六轴 Feature 扩展与 JS 采样，见 [接入指南](six_axis_integration.md) 和 [固件补丁](../native/README.md)。完整固件编译和黄山派实测仍待完成。
- 现成 Vela5 模拟器可通过本机 uORB 桥向快应用提供六轴样本；已验证非零陀螺仪进入应用。持续训练观察到真实采样缺口，尚未验收通过。
- 未安装扩展的旧固件仍缺少陀螺仪 JS API，应用会阻断完整训练；不会自动切入 Mock，也不会用零填补陀螺仪。
- 六轴模式缺少健康样本时显示未知，不使用演示心率；尚未接入步数时显示“--”。内部演示场景才生成 Mock 健康和步数。
- 模拟器不能证明真实心率质量、识别准确率、振动触感、功耗、发热或手机实际配对。
- 当前模型仍为轻量特征/规则分类器，未部署原论文深度模型。
- 默认只保存摘要、片段和数据源元信息，不保存连续波形。开发桥只在显式选择“模拟器六轴”后访问本机，不上传到外部服务器。
- 1.0.0 的截图、视频与旧验收报告作为既有演示材料保留；不作为 1.1.0 原生六轴持续训练的验收结论。
