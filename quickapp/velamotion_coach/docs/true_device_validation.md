# 黄山派与真实六轴验收

当前未连接黄山派或物理手表。以下是待执行的验收，不是通过记录。

1. 根据 [原生安装说明](../native/README.md) 核对上游 SHA、应用补丁、重新生成 JIDL 并编译固件。核验驱动确实注册两路 uORB，不只检查配置项。
2. 使用 `uorb_listener -r 50 -n 20 -t 3 sensor_accel0,sensor_gyro0` 检查浮点值、SI 单位和微秒时间戳。静置与转动时两轴组应合理变化。
3. 安装签名 1.1.0 RPK，核对设备 bundle SHA-256 与 RPK 内文件相同。在应用的同步复盘页执行设备诊断；两路都收到有效样本才算六轴通过。
4. 在教练页选择“真机”，先静置再做腕部动作，连续训练至少 15 分钟。检查 16 Hz 对齐输出、无缺帧停止、界面响应、停止后保存及重启后历史恢复。
5. 分别模拟缺少 GYRO、单轴断流、设备时钟重置、退出页面和快速停止重启；不得保存无效训练，也不得收到旧会话样本。
6. 确认真实健康/步数支持情况；未接入的数值必须显示未知。确认振动触感，记录电量、发热和掉帧。

原生六轴仅证明数据链路正确，动作分类还需带真实标签的独立人群测试。黄山派开发板也不能直接替代完整手表的佩戴、心率与功耗验证。
